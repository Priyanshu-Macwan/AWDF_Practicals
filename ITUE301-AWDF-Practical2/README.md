# ITUE301 AWDF Practical 2

A React 18 and Vite learning hub by Priyanshu Macwan (24CS049). This practical builds on the portfolio with React Router, interactive `useState` filtering, and lazy-loaded pages.

## Topics

- Rendering lifecycle
- Lazy code loading
- WCAG principles
- Progressive Web App overview
- Performance optimization
- Frontend security: XSS, CSRF, and token handling
- Automated testing at application and security levels

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Visit `/learning` to browse and filter the topics, then select a topic card to open its detail route.

The PWA page is an overview; this project does not claim installability or offline support.
